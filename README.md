# SMS Frontend

School Management System frontend built with Next.js for Admin, Teacher, and Student roles.

## Features

Role-based dashboards, student/teacher management, attendance, exams, fees, notices, and timetable.

## Tech Stack

Next.js, React, TypeScript, Tailwind CSS, TanStack Query, Zustand, Socket.IO, Axios

## Setup

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Environment

Create `.env.local`:
```bash
NEXT_PUBLIC_API_URL=http://localhost:5000/api/v1
NEXT_PUBLIC_SOCKET_URL=http://localhost:5000
```
